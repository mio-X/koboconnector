# KoboToolbox Connector for Looker Studio

This is a Looker Studio Community Connector that lets you pull data directly from your KoboToolbox forms into Looker Studio for dashboarding and visualization.

## Features
- Connects to both Global and EU KoboToolbox servers.
- Supports both API Key (Token) and Basic (Username/Password) authentication.
- Automatically handles nested repeat groups by flattening them into comma-separated strings.
- Automatically detects form languages and translates column names and multiple-choice values into your selected language.

## Usage
Add this connector in Looker Studio using the deployment ID or click the link below (replace with your active deployment ID once published):

`https://lookerstudio.google.com/datasources/create?connectorId=YOUR_DEPLOYMENT_ID`
